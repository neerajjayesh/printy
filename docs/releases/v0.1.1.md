# Release 2 — v0.1.1

An experimental update targeting incomplete prints and missing page ejection reported on an Epson L130 connected through an Airtel ZTE ZXHN F670L.

## Changes

- Correct the model-80 ESC/P2 footer: restore NVRAM (`LD`) before job end (`JE`).
- Read server replies during sending; half-close output and wait up to 90 seconds for the server before fully closing the connection.
- Increase the blocked-write deadline to 120 seconds; cancellation remains available while finishing.
- Stop automatic port probes after a print attempt for the rest of the app process.
- Add **Copy job details** with byte counts, elapsed time and connection-ending state.
- Add a **BOTTOM OF TEST PAGE** marker to separate raster completion from sheet ejection.

## Install and test

Install `printy-0.1.1-debug.apk` over Release 1 to retain saved printers. Both original APKs use the same signing certificate and application ID; version code increases to 2.

Clear any stalled job at the printer, then send one A4 test page. Check the bottom marker and complete paper ejection. Allow up to 90 seconds during “Finishing the connection.” If it stalls, copy the job details before sending another job, review any local endpoint information and include the details in a bug report.

**The physical fix on the L130/F670L has not yet been confirmed.** L120/L210 remain untested. “Sent” does not confirm physical printing or paper ejection.
