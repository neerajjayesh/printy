Release 4 addresses printing that stalls when the phone's screen times out.

### What changes

- **Screen stays on automatically** while Printy is open and a print is active. Normal timeout returns when sending finishes, fails or is canceled. This also covers queued jobs and the final connection-finishing wait.
- **Allow background printing** opens Android's approval screen so Printy can keep using the network when the phone is locked. Configure it before starting a print. If your phone still interrupts printing, open app settings and allow Unrestricted battery/background use.
- Job diagnostics now include screen, device-idle and battery-optimization state.

Printy already uses a foreground service for direct jobs and a CPU wake lock during transmission. Moving the same work into another background task would not bypass Android's power restrictions. This update adds the screen safeguard and a user-controlled battery allowance.

### Install and use

Install `printy-0.2.1-debug.apk` over the previous release; saved printers are retained. It is signed with the same certificate and uses version code 4.

For the most dependable workaround, start your print and leave Printy visible. You no longer need to tap the screen to prevent timeout. **Manually locking the phone or switching apps still permits the screen to turn off.** For that use, tap **Allow background printing** before printing and approve Android's request. Manufacturer restrictions can still vary.

This uses standard Android APIs, not a OnePlus-only workaround. Physical locked-screen testing on the reported OnePlus 13s is still pending. The screen is kept on until transmission and connection finishing end; the router cannot confirm physical paper completion.

The APK remains a debug-signed development build for Android 8.0+. Earlier releases remain available. See [verification notes](https://github.com/neerajjayesh/printy/blob/v0.2.1/docs/VERIFICATION.md) for test results.
