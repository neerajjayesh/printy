# Release 1 — v0.1.0

The initial experimental Printy build: free, open-source Android printing for Epson inkjets connected through a router's USB print server.

## Included

- Android 8.0+, Kotlin, Jetpack Compose and Material 3.
- Native Android Print Service, onboarding and saved printer profiles.
- PDF/photo import, preview, copies, color/gray, orientation and A4/Letter/4 × 6 paper.
- Standalone ESC/P2 raster encoder targeting Epson L130, L120 and L210 profiles.
- Raw TCP transport, progress, notifications and cancellation.
- Gallery/document share-sheet support.

## Known printing issue

An L130 using an Airtel ZTE ZXHN F670L printed all the initial test-page text but left the sheet inside. Longer documents repeatedly stopped around 25%. **This release is kept for historical reference; try Release 2 for the candidate fixes.** No printer profile is hardware-certified.
