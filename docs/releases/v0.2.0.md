Printy now lets you choose exactly which pages to print and fit more pages on each sheet.

### New in Release 3

- **Pages:** all pages, a list such as `1, 3–5`, odd pages or even pages.
- **Layouts:** one page, two pages side by side, or four pages in a grid.
- **Preview:** see the actual assembled sheet, original page numbers and any blank spaces before printing.
- **Reverse order:** start with the last selected page; copies remain collated.
- **Sheet counts:** the print button and job progress count physical sheets.

Open **Print a file → choose your PDF → Layout → 2 pages side by side**. Landscape is selected automatically. The controls apply in Printy's own preview; Android's native dialog continues to use its own page choices.

The owner reports successful printing with Release 2 on the Epson L130 / Airtel ZTE ZXHN F670L setup. Release 3 keeps its transport and encoder. The new layouts still need a physical print check; other model profiles remain experimental. These are single-sided layouts, not folded booklets or automatic duplex.

### Install

Download `printy-0.2.0-debug.apk`. It uses the same application ID and signing certificate as Releases 1 and 2, with version code 3, so you can install it over the previous version and retain saved printers. The `.sha256` asset identifies the APK.

This is a **debug-signed development build** for Android 8.0+. Free and open source under GPL-2.0-or-later, with no ads, analytics, subscriptions or watermarks.
